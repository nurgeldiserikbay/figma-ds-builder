ИИ для имён и структуры

ИИ даёт понятные имена классам, блокам и экранам. Вёрстку он не меняет: всё, что он предлагает, проверяется. Подключите хотя бы один вариант — программа пробует их по порядку и переходит к следующему, если лимит кончился.

Ollama на вашем компьютере, бесплатно, макеты никуда не уходят

проверяю…

  1. Скачайте Ollama и установите, как обычную программу.
  2. Вернитесь сюда и нажмите «Проверить снова» — программа сама запустит Ollama.
  3. Нажмите «Скачать модель» — один раз, несколько гигабайт.
Скачать Ollama

Хватает 8 ГБ памяти — qwen2.5-coder:7b. Слабый компьютер — qwen2.5:3b.

Ollama на другом компьютере

На том компьютере запустите Ollama с OLLAMA_HOST=0.0.0.0 и укажите здесь его адрес.

Свой ИИ любой сервис по своему ключу: OpenAI, Claude, DeepSeek, LM Studio, сервер компании…

Используется первым, если указан адрес. Платные сервисы списывают деньги по своему тарифу — на один макет уходят доли цента.

Ключи хранятся только на этом компьютере. Облачным ИИ уходят имена слоёв и короткие фрагменты текста макета, бесплатные планы могут их сохранять.

    1. Выгрузите макет из Figma

      В Figma откройте плагин DS Builder, выделите нужные фреймы и нажмите «Пакет для вёрстки». Скачается файл «… — ds-package.zip». Распаковывать его не нужно.

      Чем аккуратнее устроен файл, тем лучше вёрстка: памятка для дизайнера — Auto Layout, компоненты, состояния, переменные.

      Плагина ещё нет в Figma?

      Откройте Figma Desktop, затем Plugins → Development → Import plugin from manifest… и выберите файл packages/plugin/dist/manifest.json в папке проекта. Если файла нет, выполните npm run setup.

      Плагин входит в программу. Нажмите открыть папку с плагином, затем в Figma Desktop выберите Plugins → Development → Import plugin from manifest… и укажите в этой папке файл manifest.json. Это нужно сделать один раз.

    2. Добавьте архив сюда

      Перетащите архив сюдаили нажмите, чтобы выбрать его в папке «Загрузки». Большой файл плагин выгружает частями — добавьте все части сразу

    3. Выберите, что получить

      Дизайн-систему (цвета, шрифты, отступы) и отчёт о сверке с макетом программа делает всегда.

      Дополнительные настройки — менять не обязательно
