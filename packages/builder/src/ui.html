ds-build

вёрстка из макета Figma с проверкой пиксель в пиксель

  1. Выгрузите макет из Figma

    В Figma откройте плагин DS Builder, выделите нужные фреймы и нажмите «Пакет для вёрстки». Скачается файл «… — ds-package.zip». Распаковывать его не нужно.

    Плагина ещё нет в Figma?

    Откройте Figma Desktop, затем Plugins → Development → Import plugin from manifest… и выберите файл packages/plugin/dist/manifest.json в папке проекта. Если файла нет, выполните npm run setup.

    Плагин входит в программу. Нажмите , затем в Figma Desktop выберите Plugins → Development → Import plugin from manifest… и укажите в этой папке файл manifest.json. Это нужно сделать один раз.

  2. Добавьте архив сюда

    Перетащите архив сюдаили нажмите, чтобы выбрать его в папке «Загрузки». Большой файл плагин выгружает частями — добавьте все части сразу

  3. Выберите, что получить

    Дизайн-систему (цвета, шрифты, отступы) и отчёт о сверке с макетом программа делает всегда.

    Дополнительные настройки — менять не обязательно
