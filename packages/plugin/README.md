# Плагин Figma — Design System Extractor

Плагин анализирует все страницы и макеты файла и собирает дизайн-систему
(токены, переменные, стили, страница ДС, кандидаты в компоненты, аудит).

> **Исходники плагина ещё переносятся в репозиторий** (из `design-system-extractor.zip`).
> Сейчас здесь только новый модуль экспорта пакета для локальной программы.

## Что добавляется

`src/export-package.js` — экспорт пакета `ds-package` v1 (см. [формат](../../docs/package-format.md)):

- дерево слоёв каждого фрейма с координатами относительно фрейма, заливками, обводками,
  тенями, Auto Layout и стилями текста по фрагментам;
- эталонный PNG каждого фрейма (`exportAsync`), векторы в SVG, растровые картинки;
- `tokens.json` и `analysis.json` из анализа дизайн-системы.

План интеграции в плагин: вкладка «Экспорт» → кнопка **«Пакет для вёрстки»** →
выбор фреймов (весь файл / страница / выделение) и масштаба эталона (1× / 2×) → `.zip`.
Модуль ещё не запускался в настоящей Figma.
