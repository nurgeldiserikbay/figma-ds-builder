# figma-ds-builder — правила для работы в репозитории

- Отвечать и писать документацию на русском.
- **Сначала алгоритм, ИИ — только где без него нельзя.** Если задачу можно решить детерминированно
  (геометрия, правила, перебор с проверкой по эталону), решать кодом. ИИ — для задач «на понимание»
  (семантика, имена, адаптивность). Любой шаг ИИ проходит ту же проверку (геометрия ±0.5px + pixel diff)
  и откатывается, если результат хуже.
- Порядок ИИ: локальная модель (Ollama) → бесплатные API → платные только по явному флагу.
- **Плагин только экспортирует данные** (PNG, дерево, токены, переменные, стили, шрифты, ассеты).
  Логика вёрстки, сравнения и доработки — в `packages/builder` (платформа), не в плагине.
- Формат обмена — `docs/package-format.md`; при изменении формата править плагин и программу в одном коммите.
- В коде плагина не должно быть «import» + «(» подряд (даже в строках и комментариях) — Figma не загрузит плагин.
- Перед коммитом: `npm test` в `packages/builder` и `packages/plugin`; для изменений генератора — `npm run bench`
  в `packages/bench` и обновить `docs/benchmark.md`, если цифры изменились.
